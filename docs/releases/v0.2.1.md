**ERX Tools for Windows v0.2.1 — early beta**

This is a small update to ERX Tools, a small, offline toolbox for Windows. It fixes bugs in the Image Converter and the QR Code Generator and makes both nicer to use. It is still an **early beta**: feedback is very welcome.

## Image Converter

- Converted files now always get an "ERX" suffix before the extension (`photo.jpg` → `photoERX.png`); if that name is taken it counts up: `photoERX (1).png`, `photoERX (2).png`, …
- Output files can never overwrite each other or existing files — even when several images are converted in parallel.
- Settings panel layout polish.

## QR Code Generator

- The logo is now exactly centered; the cleared area behind it is aligned with the logo for any margin.
- The export size is a typed number (256–4096 px), and the PNG is saved at exactly that size. The default is now 1080 × 1080.
- In the Rounded style, the area behind the logo now has rounded corners.
- Save PNG / Save SVG now open a real Save dialog (with overwrite confirmation) and add the right file extension automatically.
- While a logo is added, error-correction levels other than H are greyed out and explain why when clicked.

## Which file should I download?

| Your PC | File | Size |
|---|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.2.1-x64-setup.exe` | ~2 MB |
| Most PCs, installing without internet | `ERX-Tools-0.2.1-x64-setup-with-webview2.exe` | ~210 MB |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.2.1-arm64-setup.exe` | ~2 MB |
| Windows on ARM, installing without internet | `ERX-Tools-0.2.1-arm64-setup-with-webview2.exe` | ~190 MB |

Not sure which one? Open **Settings → System → About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The small installers download Microsoft's WebView2 component during setup only if your PC does not already have it (Windows 11 and most up-to-date Windows 10 PCs have it). The "with-webview2" installers contain it, so they are much bigger but need no internet.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights. You can install it right over an older version.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools are listed in THIRD_PARTY_LICENSES.md, which is attached to this release.
