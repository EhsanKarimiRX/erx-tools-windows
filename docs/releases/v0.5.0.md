**ERX Tools v0.5.0**

This release adds a new tool, **Secure Notes**: a small encrypted notebook that opens in a window hardened against the usual browser leaks. ERX Tools is still an **early beta**: feedback is very welcome.

## Important - upgrading

Install v0.5.0 over v0.4.2 (or older): it replaces the old version normally, and your settings and data are kept. Nothing needs to be uninstalled first. There is nothing to migrate for Secure Notes, because it is new in this version.

## What's new in v0.5.0

- **Secure Notes.** Keep private notes in one encrypted file on your PC (`secure-notes.erxnotes`, with an automatic backup `secure-notes.erxnotes.bak`). The passphrase is 5 to 12 random words from the same word list as the Quantum Resistance Vault. There is no recovery: **if the words are lost, the notes are lost.**
- **Hardened window.** Secure Notes opens in its own window with an isolated, incognito profile, no autofill, no password saving, no right-click menu, no browser shortcuts, no DevTools and screen-capture protection. The window is created hidden and is shown only after every setting has been switched off and read back. Only one Secure Notes window can be open at a time.
- **Editor.** RTL-friendly text with undo/redo, search by title, a save indicator, auto-save every 2 seconds and auto-lock after 10 minutes of inactivity (configurable). An empty title is replaced by the creation date.
- **Clipboard.** Words are copied by the Rust code, never by the web page, together with marker formats that ask Windows clipboard history, the cloud clipboard and clipboard monitors to skip the text. The text is removed from the clipboard after 30 seconds if nobody else has copied, and when the app exits. Any program can still read the clipboard while the text is on it.
- **Export and restore.** Export a single note as plain text, Markdown or an encrypted `.erxnote` file, or export the whole notebook as one encrypted backup. Restoring appends the notes and regenerates duplicate ids; it never replaces your existing notes.
- **Settings.** Preview mode (titles or first line), auto-lock minutes, and changing the passphrase. Changing the passphrase re-encrypts the file with new words and new keys.
- **Storage.** Atomic saves with a backup, recovery from the backup when the main file is missing or damaged, and a safety check that reads every saved file back. The file size is only shown in steps of 256 KiB.
- **Vazirmatn font.** Bundled for the Secure Notes window (SIL Open Font License 1.1).

The encrypted container format is documented in `docs/NOTES_FORMAT.md` in the source tree.

## Which file should I download?

| Your PC | File |
|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.5.0-x64-setup.exe` |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.5.0-arm64-setup.exe` |

Not sure which one? Open **Settings → System → About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The installer downloads Microsoft's WebView2 component during setup only if your PC does not already have it.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC." Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools are listed in `THIRD_PARTY_LICENSES.md`, which is attached to this release.

## Known issues

- **Secure Notes has no recovery.** If the words are lost, the notes are lost. There is no password reset.
- **Secure Notes has had no professional security audit.** The container is new; keep another backup of anything you cannot replace.
- **Clipboard history skipping is proven by hand.** Whether Windows really skips the text in clipboard history is checked with Win+V on a real build, not by an automated test.
- **After a hard kill** the temporary profile folder of Secure Notes stays on disk until the next start, where it is swept.
- **Screenshot protection** was tested with Win+Shift+S and PrintScreen only; screen recording, Windows Recall and remote-control tools were not tested.
- If the last part of a split encrypted file is missing, the Vault cannot know that more data was expected and reports a damaged file instead of a missing part.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
- Favicons does not draw text: an SVG logo that contains text is rendered without that text, and the tool warns you when it happens. JPEG logos have no transparency, which also shows in the saved icons; the tool warns about that too.
- Metadata Remover keeps the colour profile of a HEIC photo, because the profile belongs to the picture itself; the tool says so instead of pretending to remove it.
- This version was tested by hand on Windows 11 (x64) only. Windows 10 and ARM64 have not been tested.
