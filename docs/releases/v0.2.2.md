**ERX Tools for Windows v0.2.2 — early beta**

This is a small update to ERX Tools, a small, offline toolbox for Windows. It gives the app a new name and improves the System Manager. It is still an **early beta**: feedback is very welcome.

## Important — upgrading from v0.2.0 or v0.2.1

The app now has a new installed name, **ERX Tools**, so Windows treats this version as a separate app: it does **not** replace the old "ERX Tools for Windows" automatically. Please do it in this order:

1. **If you use Awake**, open the old app and turn Awake **off** first. Uninstalling does not restore your power settings.
2. **Uninstall the old app:** Settings → Apps → Installed apps → **ERX Tools for Windows** → Uninstall. If the uninstaller asks about the application data, **do not tick "Delete the application data"**, so your data is kept.
3. **Install ERX Tools v0.2.2** (see the downloads below).

Please do not run the old and the new app at the same time. If you pinned the old app to the taskbar, pin the new "ERX Tools" again.

## What's new in v0.2.2

- **New name:** the app is now called **ERX Tools** (installed app name, Start menu and desktop shortcut, window title and home screen). The GitHub project keeps its name.
- **Desktop Icons (System Manager):** the **Control Panel** icon now turns on correctly. A new button, **Open Windows desktop icon settings**, opens Windows' own settings window for desktop icons. A new note explains that Windows may move your other desktop icons into the free spot when you hide an icon.
- **Command Tips (System Manager):** redesigned. Every command is now in its own card, the category headings are gone, and the commands you most likely need come first. Text you must replace (a folder path, a file path, a network name) is now realistic sample text shown in **green**, with a note under the command, instead of text in angle brackets (which broke the commands in PowerShell). Commands with several steps have one box and one Copy button per step.
- **Safer app updates:** the "Update all apps" command (`winget upgrade --all`) was removed, because updating everything at once can break tools such as Python. Use "List app updates", then "Update one app" to update only the apps you really need.
- **New hardware checks** (in "More commands"): graphics card details, laptop model and serial number from the BIOS, RAM modules and total size, and SSD/hard drive model and size. They are useful for checking a second-hand or suspicious PC. ERX Tools only shows the text; you run the commands yourself.
- Small internal cleanup (an unused-code warning in release builds).

## Which file should I download?

| Your PC | File | Size |
|---|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.2.2-x64-setup.exe` | ~2 MB |
| Most PCs, installing without internet | `ERX-Tools-0.2.2-x64-setup-with-webview2.exe` | ~210 MB |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.2.2-arm64-setup.exe` | ~2 MB |
| Windows on ARM, installing without internet | `ERX-Tools-0.2.2-arm64-setup-with-webview2.exe` | ~190 MB |

Not sure which one? Open **Settings → System → About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The small installers download Microsoft's WebView2 component during setup only if your PC does not already have it (Windows 11 and most up-to-date Windows 10 PCs have it). The "with-webview2" installers contain it, so they are much bigger but need no internet.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights. If you already have **ERX Tools for Windows** (v0.2.0 or v0.2.1), uninstall it first — see the upgrade notes above.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools are listed in THIRD_PARTY_LICENSES.md, which is attached to this release.

## Known issues

- When you hide a desktop icon (in ERX Tools or in Windows' own settings), Windows may move your other desktop icons into the free spot. This is how Windows behaves; ERX Tools never moves or saves your icon positions.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
