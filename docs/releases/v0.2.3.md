**ERX Tools for Windows v0.2.3 — early beta**

This update adds a new tool for website icons, an About button, faster folder icons and two new commands. ERX Tools is still an **early beta**: feedback is very welcome.

## Important — upgrading

Install v0.2.3 over v0.2.2: it replaces it normally, and your settings and data are kept. Nothing needs to be uninstalled first.

If you still have the old **"ERX Tools for Windows"** (v0.2.0 or v0.2.1), that note from the v0.2.2 release applies only to that old app: turn Awake off in it, uninstall it, do not tick "Delete the application data", and then install v0.2.3.

## What's new in v0.2.3

- **New tool: Favicons.** Create a complete favicon package for a website from one logo image. Drop a square image of at least 512 × 512 pixels (or an SVG) and get `favicon.ico`, PNG icons, an Apple touch icon, Android icons (including a maskable one), a `site.webmanifest` and a ready-to-paste HTML snippet. Inputs: PNG, JPEG, WebP, BMP, GIF, TIFF, ICO and SVG. There are two padding options for the icons, and everything is created on your PC — nothing is uploaded.
- **About button:** a round **i** button at the bottom-right of the home screen opens a short About dialog with the app version and a **View on GitHub** button.
- **Folder Icon Changer — much faster icons, and shortcuts.** A changed folder icon now usually appears within a few seconds instead of after a long wait. Windows shortcuts (`.lnk`) can be dropped in too: the shortcut's own icon changes and its target is not touched.
- **Command Tips (System Manager) — two new commands:** **List installed apps** and **Save installed apps to a file**. They cover the classic desktop programs and the Microsoft Store apps of your Windows account (portable apps that were never installed are not listed). Long commands now start collapsed with a **More/Less** button, so the list stays readable; **Copy** always copies the full command.
- Small internal cleanup: the temporary timing instrumentation from the folder-icon investigation was removed.

## Which file should I download?

| Your PC | File | Size |
|---|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.2.3-x64-setup.exe` | ~2 MB |
| Most PCs, installing without internet | `ERX-Tools-0.2.3-x64-setup-with-webview2.exe` | ~210 MB |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.2.3-arm64-setup.exe` | ~2 MB |
| Windows on ARM, installing without internet | `ERX-Tools-0.2.3-arm64-setup-with-webview2.exe` | ~190 MB |

Not sure which one? Open **Settings → System → About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The small installers download Microsoft's WebView2 component during setup only if your PC does not already have it (Windows 11 and most up-to-date Windows 10 PCs have it). The "with-webview2" installers contain it, so they are much bigger but need no internet.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights. If you already have ERX Tools (v0.2.2), just install it — the new version replaces the old one.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools are listed in THIRD_PARTY_LICENSES.md, which is attached to this release.

## Known issues

- When you hide a desktop icon (in ERX Tools or in Windows' own settings), Windows may move your other desktop icons into the free spot. This is how Windows behaves; ERX Tools never moves or saves your icon positions.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
- A changed folder icon usually appears within a few seconds, but an Explorer window that already cached the old icon may still need a Refresh (or opening another folder and coming back).
- Favicons does not draw text: an SVG logo that contains text is rendered without that text, and the tool warns you when it happens. JPEG logos have no transparency, which also shows in the saved icons; the tool warns about that too.
