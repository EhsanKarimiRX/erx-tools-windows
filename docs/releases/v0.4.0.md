**ERX Tools v0.4.0**

This update adds a device information card to System Manager and a new tool, **Metadata Remover**, that removes hidden data from photos and videos without re-encoding them. ERX Tools is still an **early beta**: feedback is very welcome.

## Important - upgrading

Install v0.4.0 over v0.3.0 (or older): it replaces the old version normally, and your settings and data are kept. Nothing needs to be uninstalled first.

## What's new in v0.4.0

- **System Manager: a device card at the top.** It shows your processor, graphics card, RAM, drives, Windows version and battery health (or uptime on a PC without a battery). It is read again every time System Manager opens, changes nothing and sends nothing anywhere; whatever Windows does not report is shown as "Not reported".
- **New tool: Metadata Remover.** It shows what is hidden inside a photo or video, and saves a clean copy with that data removed. Your original is never changed or deleted.
  - **Formats:** JPEG, PNG, WebP, GIF, BMP, TIFF, HEIC/HEIF, MP4, MOV, MKV and WebM. The type is read from the content, never from the extension. A BMP, and a TIFF that has nothing hidden, is reported as "This file has no metadata." and no copy is made.
  - **Not supported:** AVIF, M4V, audio files, Word documents and PDF files. An M4V file is recognized by its content (an M4V brand in the file header), not by its name. Also refused: BigTIFF, TIFF files with more than one page, TIFF files with sub-pictures, and RAW/DNG files.
  - **What is removed:** in photos, the EXIF block (GPS location, camera and lens, dates, serial numbers, maker notes, an embedded thumbnail), XMP, comments, Photoshop and IPTC data, text chunks and any data after the end of the image. In videos, metadata boxes and user data, the timed-metadata tracks (location, motion) together with their samples, and the creation and modification times; in MKV, the Tags element, attached pictures, the title and date, and the names of the muxing and writing programs. In HEIC, the Exif and XMP items. In TIFF, the metadata entries of the directory and the Exif and GPS directories.
  - **Nothing is re-encoded.** Photos lose their metadata segments and chunks while their picture data is copied unchanged. Videos, HEIC and TIFF files are changed in place, so their size stays exactly the same.
  - **Kept by default:** the photo rotation (phone photos stay upright) and the colour profile (colours stay the same). You can turn either off; then colours may look different. HEIC always keeps its rotation and its profile; TIFF always keeps its rotation.
  - **Your files stay yours:** every new file gets "ERX" before the extension (photo.jpg becomes photoERX.jpg), a taken name counts up, and an existing file is never overwritten. The original file is only read.
  - **Checked before saving:** the new copy is scanned again and, for photos, its pixels are compared with the original. If a check fails, the copy is not kept and the file is reported as failed.
  - **Batches:** up to 200 files, two at a time, with live progress and a Cancel button that also removes the files that were being written.
  - **Limits, honestly:** only metadata fields are removed. The tool cannot remove what is visible in the picture or video, watermarks, the file name, the dates of the new file, traces inside the video stream itself (for example an encoder name), or other copies of the file. It is not a guarantee of anonymity.
- **More than 800 automated tests** now check the app, including the new tool and its safety checks.

## Before you rely on Metadata Remover

- **Only the hidden fields go.** Anything you can see in the picture or video stays, and so do the file name and the dates of the new file.
- **A clean copy can still look like itself.** Removing metadata does not blur, crop or change the picture; if the image content alone identifies you (a face, a house, a reflection), the copy still does.
- **HEIC needs Windows codecs only for the comparison.** A HEIC photo is cleaned even without Microsoft's HEIF and HEVC extensions; when they are missing, the pixel comparison is skipped and the app says so.
- **Tested by hand on Windows 11 (x64) only.** Windows 10 and ARM64 have not been tested. WebM, AVIF and audio files were not tried with real samples, and the M4V refusal is covered by automated tests only.

## Which file should I download?

| Your PC | File | Size |
|---|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.4.0-x64-setup.exe` | about 4.2 MB |
| Most PCs, installing without internet | `ERX-Tools-0.4.0-x64-setup-with-webview2.exe` | about 212 MB |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.4.0-arm64-setup.exe` | about 3.8 MB |
| Windows on ARM, installing without internet | `ERX-Tools-0.4.0-arm64-setup-with-webview2.exe` | about 188 MB |

Not sure which one? Open **Settings -> System -> About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The small installers download Microsoft's WebView2 component during setup only if your PC does not already have it (Windows 11 and most up-to-date Windows 10 PCs have it). The "with-webview2" installers contain it, so they are much bigger but need no internet.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu. Metadata Remover is on the home screen.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools, including the EFF word list, are listed in THIRD_PARTY_LICENSES.md, which is attached to this release.

## Known issues

- When you hide a desktop icon (in ERX Tools or in Windows' own settings), Windows may move your other desktop icons into the free spot. This is how Windows behaves; ERX Tools never moves or saves your icon positions.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
- Favicons does not draw text: an SVG logo that contains text is rendered without that text, and the tool warns you when it happens. JPEG logos have no transparency, which also shows in the saved icons; the tool warns about that too.
- Metadata Remover keeps the colour profile of a HEIC photo, because the profile belongs to the picture itself; the tool says so instead of pretending to remove it.
