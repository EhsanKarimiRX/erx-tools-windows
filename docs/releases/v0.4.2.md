**ERX Tools v0.4.2**

This update changes how the Quantum Resistance Vault names the parts of a split file, and reduces the downloads to two installers. ERX Tools is still an **early beta**: feedback is very welcome.

## Important - upgrading

Install v0.4.2 over v0.4.1 (or older): it replaces the old version normally, and your settings and data are kept. Nothing needs to be uninstalled first.

**If you use the Vault with split files, please read the next section first.**

## What's new in v0.4.2

- **Split parts have a new name.** When the Vault splits an encrypted file into parts, the parts are now named `name.001.erx`, `name.002.erx` and so on, so every part ends in `.erx`. Before, they were named `name.erx.001`, `name.erx.002`. To decrypt, select `name.001.erx`. Keep the part names as they are.
- **Split files made by older versions need a manual rename.** v0.4.2 does not open parts named `name.erx.001`. Rename each part by hand (`name.erx.001` becomes `name.001.erx`, `name.erx.002` becomes `name.002.erx`, and so on) and select `name.001.erx`. If you select an old-style first part, the app now explains this. Encrypted files that were not split are not affected. Split files made by v0.4.2 cannot be opened by v0.4.1 or older.
- **Parts are matched by what is inside them.** The app decides which files belong together from the information stored in each file, not from the number in the name. Two separate encrypted files with names like `scan.001.erx` and `scan.002.erx` are not mixed up.
- **Only two installers.** The downloads are now `ERX-Tools-0.4.2-x64-setup.exe` and `ERX-Tools-0.4.2-arm64-setup.exe`. The big "with-webview2" files are gone. Setup downloads Microsoft's WebView2 component only if your PC does not already have it (Windows 11 and most up-to-date Windows 10 PCs do). A PC that has no WebView2 and no internet connection must install Microsoft's WebView2 Runtime first.

## Which file should I download?

| Your PC | File |
|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.4.2-x64-setup.exe` |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.4.2-arm64-setup.exe` |

Not sure which one? Open **Settings → System → About** and look at **System type**: “x64-based processor” means x64; “ARM-based processor” means ARM64.

The installer downloads Microsoft's WebView2 component during setup only if your PC does not already have it.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights.
2. The installers are **not code-signed**, so Windows SmartScreen may show “Windows protected your PC.” Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools are listed in `THIRD_PARTY_LICENSES.md`, which is attached to this release.

## Known issues

- If the last part of a split encrypted file is missing, the Vault cannot know that more data was expected and reports a damaged file instead of a missing part.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
- Favicons does not draw text: an SVG logo that contains text is rendered without that text, and the tool warns you when it happens. JPEG logos have no transparency, which also shows in the saved icons; the tool warns about that too.
- Metadata Remover keeps the colour profile of a HEIC photo, because the profile belongs to the picture itself; the tool says so instead of pretending to remove it.
- This version was tested by hand on Windows 11 (x64) only. Windows 10 and ARM64 have not been tested.
