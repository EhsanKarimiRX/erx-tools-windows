**ERX Tools v0.5.1**

This release fixes how encrypted note exports (`.erxnote` files) are protected. ERX Tools is still an **early beta**: feedback is very welcome.

## Important - read this first

In v0.5.0 every `.erxnote` file (a single note or a backup of the whole notebook) was encrypted with the same fixed password that is built into the program. Anyone who has such a file can open it, even without your words. So a `.erxnote` file made by v0.5.0 is effectively **not protected**.

What to do:

1. Install v0.5.1 over v0.5.0 (see "Upgrading" below).
2. Restore each old `.erxnote` file that you still need. v0.5.1 opens it at once and shows a notice. Then export the notes again with the new options and delete the old file.
3. Deleting a file does not remove copies made earlier (a cloud folder, a USB stick, an e-mail). Those copies can still be opened by anyone.
4. Files exported by v0.5.1 cannot be opened by v0.5.0: it says that the file needs a different version of ERX Tools. Update every PC where you want to open them.

## Upgrading

Install v0.5.1 over v0.5.0 (or older): it replaces the old version normally, and your settings and data are kept. Nothing needs to be uninstalled first. Your notebook file (`secure-notes.erxnotes`) is not changed and opens with the same words as before. There is nothing to migrate.

## What's new in v0.5.1

- **A real password for every export.** After you choose an encrypted `.erxnote` export, you pick its password: your current Secure Notes password (you type the words again, and they are checked against your notebook) or new random words made for that file (5 to 12 words). With new words you copy them, confirm that you saved them and type them again before the file is written. The fixed built-in password is never used for writing any more.
- **Backup of the whole notebook.** The backup in Settings has the same two choices. It is always encrypted.
- **Restore asks for the words.** Plain text files and files made by v0.5.0 are restored at once (the old files with a notice). Every other encrypted file asks for its words. If the words are wrong you can try again, and nothing is imported until they are right. Restoring still only adds notes; it never replaces your existing notes.
- **Safer file writing.** An export is written to a temporary file first, checked, and then moved to the name you chose.
- **Small interface changes.** The export button says "Use current Secure Notes password". The words panel keeps one width. The restore prompt shows moving stripes while the words are checked (about one second).
- **File format.** New exports set a flag in the file header (`FLAG_USER_PASSPHRASE`). The container version is still 1. The format is documented in `docs/NOTES_FORMAT.md` in the source tree.

## Which file should I download?

| Your PC | File |
|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.5.1-x64-setup.exe` |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.5.1-arm64-setup.exe` |

Not sure which one? Open **Settings > System > About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The installer downloads Microsoft's WebView2 component during setup only if your PC does not already have it.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC." Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools are listed in `THIRD_PARTY_LICENSES.md`, which is attached to this release.

## Known issues

- **Export words cannot be recovered.** If you lose the words of an export, that file is lost. There is no password reset.
- **Exports are only as strong as their words.** An export made with your current Secure Notes password is only as strong as that password. Changing the Secure Notes password later does not change older exports; restoring an older export then needs the old words. Export words of 5 to 7 words are allowed, with a warning.
- **Old v0.5.0 exports stay weak.** They use the fixed built-in password. Export them again and delete the old files.
- **No limit on wrong guesses in the restore prompt.** Each guess takes about one second, and the file is offline, so a short password can be guessed.
- **Text and Markdown exports are plain text.** They are not encrypted.
- **The export dialog and the restore prompt do not trap the Tab key.** Tab can move to the page behind them.
- **A crash during an export** can leave a temporary `*.erxtmp` file next to the file you chose. It can be deleted.
- **Secure Notes has no recovery.** If the words of your notebook are lost, the notes are lost.
- **Secure Notes has had no professional security audit.** Keep another backup of anything you cannot replace.
- **Clipboard history skipping is proven by hand.** Whether Windows really skips the text in clipboard history is checked with Win+V on a real build, not by an automated test.
- **After a hard kill** the temporary profile folder of Secure Notes stays on disk until the next start, where it is swept.
- **Screenshot protection** was tested with Win+Shift+S and PrintScreen only; screen recording, Windows Recall and remote-control tools were not tested.
- If the last part of a split encrypted file is missing, the Vault cannot know that more data was expected and reports a damaged file instead of a missing part.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
- Favicons does not draw text: an SVG logo that contains text is rendered without that text, and the tool warns you when it happens. JPEG logos have no transparency, which also shows in the saved icons; the tool warns about that too.
- Metadata Remover keeps the colour profile of a HEIC photo, because the profile belongs to the picture itself; the tool says so instead of pretending to remove it.
- This version was tested by hand on Windows 11 (x64) only. Windows 10 and ARM64 have not been tested.
