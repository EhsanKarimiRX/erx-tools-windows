**ERX Tools v0.3.0**

This update adds a new tool, the **Quantum Resistance Vault**, for encrypting files and folders with a passphrase, and two new commands in System Manager. ERX Tools is still an **early beta**: feedback is very welcome.

## Important - upgrading

Install v0.3.0 over v0.2.3 (or v0.2.2): it replaces the old version normally, and your settings and data are kept. Nothing needs to be uninstalled first.

## What's new in v0.3.0

- **New tool: Quantum Resistance Vault.** Encrypt a file or a whole folder with a passphrase, and decrypt it again later. Everything happens on your PC; nothing is uploaded.
  - **A passphrase of random words.** The app creates 6 to 12 random words (10 by default) from the EFF Large Wordlist. You save them, confirm, and encrypt. To decrypt, you type the words.
  - **Designed to resist quantum computers.** It uses only symmetric encryption (XChaCha20-Poly1305 with a 256-bit key) and Argon2id to turn your words into the key. This is a design goal, not a guarantee; see the limits below.
  - **Big files, small memory.** Big files are processed as a stream; we tested files up to 8 GB. The data is compressed with Zstandard when that helps. The result can be split into parts of 500 MB, 1 GB or 2 GB. Progress is live, and you can cancel at any time without leaving files behind.
  - **Careful with your files.** The original is never changed, an existing file is never overwritten, and the new file is checked after it is written. The original name is stored inside the encryption and the output name hides the file type (photo.jpg becomes photo.erx); the real name comes back when you decrypt.
  - **Whole folders.** A folder becomes one encrypted file with its structure inside. Links and special items cannot be encrypted. File dates and attributes are not stored.
  - In our tests an 8 GB folder was encrypted in about a minute while the app used under 20 MB of memory (your disk speed matters).
- **Command Tips (System Manager): two new commands** that turn Windows' internet-connection check off and on. They need PowerShell as administrator, and Windows may need a restart before the change takes effect. ERX Tools only shows the text; you run the commands yourself.
- More than 600 automated tests now check the app, including tests with multi-gigabyte files.

## Before you rely on the Vault

- **No recovery.** If you lose the words, nobody can open your files, not even the author. Keep the words safe.
- **No professional security audit.** The Vault is built from well-known open-source cryptography libraries, but ERX Tools itself is new and has not been audited. Keep a second backup of anything you cannot replace.
- **The original stays.** After encrypting, your original file or folder is still there. Delete it yourself when you are sure the encrypted copy works. A normal delete is not a secure erase.
- **What an encrypted file still shows.** Anyone can see that it is an ERX file, its approximate size, how many parts there are, whether it holds a file or a folder, and whether it was compressed. File names, file types and the folder structure are hidden.
- **It cannot protect a compromised PC.** Malware, a keylogger, or someone who sees or gets your words can defeat any encryption. While you use the Vault, the words are kept in the app's memory.
- Tested by hand on **Windows 11 (x64)** only. **Windows 10** and **ARM64** have not been tested.

## Which file should I download?

| Your PC | File |
|---|---|
| Most PCs (Intel or AMD) | `ERX-Tools-0.3.0-x64-setup.exe` |
| Most PCs, installing without internet | `ERX-Tools-0.3.0-x64-setup-with-webview2.exe` |
| Windows on ARM (for example Snapdragon laptops) | `ERX-Tools-0.3.0-arm64-setup.exe` |
| Windows on ARM, installing without internet | `ERX-Tools-0.3.0-arm64-setup-with-webview2.exe` |

Not sure which one? Open **Settings -> System -> About** and look at **System type**: "x64-based processor" means x64; "ARM-based processor" means ARM64.

The small installers download Microsoft's WebView2 component during setup only if your PC does not already have it (Windows 11 and most up-to-date Windows 10 PCs have it). The "with-webview2" installers contain it, so they are much bigger but need no internet.

## Installing

1. Download the file for your PC and double-click it. ERX Tools installs for your user account and does not need administrator rights.
2. The installers are **not code-signed**, so Windows SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**. Some antivirus programs may also warn about unsigned programs.
3. Start ERX Tools from the Start menu.

## Check your download (optional)

`SHA256SUMS.txt` lists the SHA-256 checksum of each installer. In PowerShell, run `Get-FileHash .\<file name> -Algorithm SHA256` and compare the result with that file. The licenses of the third-party components used in ERX Tools, including the EFF word list, are listed in THIRD_PARTY_LICENSES.md, which is attached to this release.

## Known issues

- When you hide a desktop icon (in ERX Tools or in Windows' own settings), Windows may move your other desktop icons into the free spot. This is how Windows behaves; ERX Tools never moves or saves your icon positions.
- Awake changes only the sleep, hibernate and screen-off timers of your current power plan. It does not change what happens when you close a laptop lid or press the power button.
- Favicons does not draw text: an SVG logo that contains text is rendered without that text, and the tool warns you when it happens. JPEG logos have no transparency, which also shows in the saved icons; the tool warns about that too.
